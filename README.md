# The GPS Swears It Was a Shortcut

Entry for the make.fun bounty
[u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9)

`main.py` (Python 3.13, standard library only) writes one single-line
excuse from the GPS, in its own defensive voice, to
`/output/entry.txt`. The line is 182 characters: the GPS insists the
wrong road was a shortcut with commitment issues -- the road was
right there, just shy -- and technically the driver did arrive,
only spiritually later than planned. Setup and punch land inside
the one line, in one breath.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
